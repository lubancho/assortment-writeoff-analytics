Проблемы и рекомендации

Каждая задача — что проверить, почему и с какими ограничениями. Задачи не утверждают причину и не предлагают выводить товар из ассортимента только по классу ABC/XYZ.

Задачи — по всей сети за последние 28 дней (до ); фильтр категории применяется.

Товары — по всей сети за последние 28 дней. Доля списаний сравнивается с медианой своей категории: у свежей продукции списания выше по природе. Как считается доля — в разделе «Аналитика → Методика».

Где маржа ниже, чем по сети: факт, с чем сравниваем, насколько хуже и что проверить. Возможные факторы — гипотезы, а не установленные причины.
