# 06. Макеты интерфейса

Экран ноутбука 1366–1440 px. Боковая панель 260 px: навигация, **общие фильтры периода и точек** (действуют на всех экранах). Стиль — как в проекте №1: нейтральная палитра, белые карточки, сине-серый акцент; цвет никогда не единственный носитель смысла.
