# 04. Методика: метрики, ABC, XYZ, списания, рекомендации

Код: `src/asa/metrics.py`, `abc.py`, `xyz.py`, `recommendations.py`; SQL — `src/asa/sql/`.

## 1. Общие правила

- Деньги — `NUMERIC` в базе и `Decimal` в Python; `float` — только для графиков.
- Знаменатель 0, отрицательный или неизвестный → «н/д», а не 0.
- Показатели групп — отношение сумм, а не среднее отношений.
- Отменённая операция не участвует ни в чём; возврат уменьшает выручку, количество и себестоимость продаж.
- Период включительный, дата — по местному времени точки.

## 2. Метрики

| Метрика | Формула | Единица | Период | Знаменатель / агрегация | Нулевые и особые случаи |
|---|---|---|---|---|---|
| Выручка | Σ (кол-во × цена − скидка) со знаком операции | ₽ | выбранный | сумма по строкам | нет продаж → 0 |
| Количество продаж | Σ количества со знаком | шт | выбранный | сумма | может быть ≤ 0 при возвратах |
| Валовая прибыль | выручка − себестоимость проданного (по версии на дату продажи) | ₽ | выбранный | сумма | строки без себестоимости на дату исключаются, их число показывается |
| Маржинальность | валовая прибыль / выручка тех же строк | % | выбранный | отношение сумм | выручка ≤ 0 → н/д |
| Средний чек | выручка / число чеков | ₽ | выбранный | чек = заказ (`order_id`) с неотменённой продажей | нет чеков → н/д. **Не считается по строкам без номера заказа** |
| Оборачиваемость | себестоимость продаж / средний дневной запас, доступный к продаже | раз за период | выбранный | средний запас = Σ по дням (остаток на начало + выпуск) × себестоимость / число дней | запас 0 → н/д |
| Дни запаса | остаток на конец периода в себестоимости / средняя дневная себестоимость продаж | дни | конец периода | — | нет продаж → н/д. Для свежей продукции ≈ 0 по природе |
| Стоимость списаний | Σ количество × себестоимость на дату списания | ₽ | выбранный | сумма | — |
| Доля списаний | списания / (себестоимость продаж + списания) | % | выбранный | **себестоимость выпуска** — всего, что было выставлено к продаже | знаменатель 0 → н/д |
| Доля дней без товара | рабочие точко-дни, когда товара не было в продаже / все рабочие точко-дни | % | выбранный | точко-день = точка × дата, точка открыта | нет рабочих дней → н/д |
| Доля дней «распродано» | точко-дни, когда к закрытию ничего не осталось / рабочие точко-дни | % | выбранный | то же | информационная: для свежей продукции это может быть и точным планированием |
| Вклад категории | показатель категории / показатель сети | % | выбранный | итог сети | при убыточных категориях доли могут быть > 100% и < 0% |
| Динамика | показатели по дням, скользящая средняя за 7 дней | ₽ | выбранный | дни без продаж выводятся как 0 (календарь `generate_series`) | — |

**Почему доля списаний — к себестоимости выпуска, а не к выручке:** списание — это потеря себестоимости. Сравнение с выручкой смешивает потери с наценкой: товар с высокой ценой выглядел бы «лучше» при тех же физических потерях.

## 3. ABC-анализ

- **Объект:** товар в целом по сети за выбранный период.
- **Показатель:** выручка **или** валовая прибыль — две независимые классификации, классы не смешиваются.
- **Сортировка:** по значению по убыванию; при равенстве — по `product_id` по возрастанию (воспроизводимо).
- **Доля:** значение / сумма **положительных** значений.
- **Граница:** класс определяется накопленной долей **до** товара: `< A` → A, `< B` → B, иначе C. Товар, на котором накопленная доля пересекает границу, остаётся в старшем классе. Пример: доли 50, 25, 10, 8% — третий товар начинается с 75% (< 80%), поэтому A, хотя с ним накопленная доля 85%.
- **Пороги по умолчанию:** A — 80%, B — 95%; настраиваются на экране «Ассортимент», должны удовлетворять 0 < A < B < 100%.
- **Нулевой и отрицательный вклад:** класс C с пометкой «нет продаж» / «отрицательный вклад»; в знаменатель долей не входят.
- **Сверка:** SQL-задача 8 и `asa.abc` дают одинаковые классы (тест для обоих показателей).

## 4. XYZ-анализ

- **Окно:** последние 12 полных недель (пн–вс) до конца выбранного периода, но не раньше начала данных. Окно фиксировано и не зависит от длины выбранного периода — иначе при периоде в 4 недели наблюдений не хватило бы.
- **Шаг:** неделя; продажи товара по сети в целом.
- **Коэффициент вариации:** CV = σ / μ, σ — по генеральной совокупности (`ddof=0`).
- **Пороги по умолчанию:** X — CV ≤ 10%, Y — ≤ 25%, Z — > 25%; настраиваются.
- **Отсутствие товара:** доступность недели = рабочие точко-дни с товаром в продаже / рабочие точко-дни. Недели с доступностью < 80% исключаются: низкие продажи в них не означают низкий спрос.
- **Малое число наблюдений:** < 6 пригодных недель → класс не присваивается («недостаточно наблюдений»).
- **Недостаточная история:** первая продажа товара позже чем через 13 дней после начала окна → «недостаточная история».
- **Нет продаж:** сумма за пригодные недели 0 → «нет продаж».
- **Сезонность:** опция «убрать линейный тренд» — CV считается по отклонениям от линейного тренда. Без неё растущий или падающий спрос (например, напитки к осени) завышает CV.

## 5. Анализ списаний

Количество и стоимость списаний, разрезы по причинам (истёк срок, брак, возврат), категориям, точкам, дням; доля в себестоимости выпуска. Сравнение товара — с медианой **своей категории**: у свежей продукции списания выше по природе, и сравнивать её с напитками некорректно.

## 6. Правила рекомендаций

| Правило | Условие (пороги по умолчанию) | Важность | Действие |
|---|---|---|---|
| R1. Высокая выручка и низкая маржа | ABC по выручке = A и маржинальность ниже сетевой более чем на 5 п. п. | Высокая | Проверить себестоимость, цену и промо |
| R2. Стабильный спрос и частое отсутствие | XYZ = X или Y и товара не было в продаже в ≥ 3% рабочих точко-дней (типичная цель доступности — 97%) | X — высокая, Y — средняя | Проверить план производства и страховой запас |
| R3. Высокие списания | Доля списаний ≥ 20% и выше медианы своей категории на ≥ 15 п. п. | Высокая при превышении медианы на ≥ 30 п. п., иначе средняя | Сверить объём производства с продажами по дням недели, уточнить прогноз |
| R4. Низкий вклад и нестабильный спрос | ABC по выручке = C и XYZ = Z | Низкая | Дополнительная ассортиментная оценка — **не** вывод из ассортимента |
| R5. Прибыль падает при росте выручки | Выручка выросла, валовая прибыль снизилась более чем на 3% к предыдущему периоду той же длины | Средняя | Проверить маржу, скидки и структуру продаж |

R5 не применяется, если предыдущий период выходит за начало данных — неполное сравнение было бы нечестным.

Каждая рекомендация содержит: **название проблемы, основание в данных, значение показателя, возможную причину, рекомендуемое действие, ограничения интерпретации**. Формулировки причин — «возможная», а не утверждение: правило фиксирует совпадение показателей, а не причинно-следственную связь.

### Как подбирались пороги (честно)

Пороги R2 и R3 уточнены после просмотра демо-данных: при едином пороге 20% для списаний правило срабатывало у 102 из 150 товаров (почти вся свежая продукция) и теряло смысл; при пороге доступности 8% R2 не срабатывало ни разу. Это настройка под синтетические данные; на реальных данных пороги нужно согласовывать с бизнесом.
