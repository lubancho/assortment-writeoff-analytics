# 02. Требования, сценарии, критерии приёмки и трассировка

## 1. Бизнес-правила

| ID | Правило |
|---|---|
| BR-01 | Отменённые операции не учитываются; возвраты вычитаются из выручки, количества и себестоимости |
| BR-02 | Себестоимость продажи и списания — по версии на дату операции |
| BR-03 | Средний чек считается только по чекам (`order_id`), не по строкам |
| BR-04 | ABC по выручке и ABC по прибыли — независимые классификации |
| BR-05 | ABC: сортировка по убыванию, при равенстве — по `product_id`; товар на границе остаётся в старшем классе; вклад ≤ 0 → C |
| BR-06 | XYZ: недели с доступностью товара < 80% не используются; < 6 недель — класс не присваивается |
| BR-07 | Доля списаний — к себестоимости выпуска (продажи + списания по себестоимости) |
| BR-08 | Списания товара сравниваются с медианой его категории |
| BR-09 | Рекомендация не утверждает причину и не предлагает вывести товар только по классу ABC/XYZ |
| BR-10 | Сравнение с предыдущим периодом выполняется только при полном предыдущем периоде в данных |

## 4. Сценарии

**UC-01. Обзор недели.** Руководитель выбирает период, видит выручку, прибыль, маржу, списания, активные SKU, средний чек с изменением к прошлому периоду и сравнение точек.

**UC-02. Ревизия ассортимента.** Категорийный менеджер смотрит ABC по выручке и прибыли, матрицу ABC×XYZ, выбирает товар и видит недельный спрос с пометкой непригодных недель.

**UC-03. Разбор списаний.** Менеджер по производству смотрит причины, категории и точки, список товаров со списаниями выше нормы категории.

**UC-04. Рекомендации.** Пользователь фильтрует рекомендации по важности и правилу, читает основание и ограничения.

**UC-05. Отчёт.** Пользователь выбирает SQL-задачу, читает её документацию, выгружает результат или сводный отчёт в Excel.

## 5. Критерии приёмки

| ID | Критерий | Требования |
|---|---|---|
| AC-01 | Итоги SQL-задач 1, 2, 3, 5, 9 сходятся с итогом сети | FR-02, FR-07 |
| AC-02 | Выручка, себестоимость, количество, чеки и средний чек в SQL и Python совпадают | NFR-03 |
| AC-03 | ABC в SQL и Python совпадают для выручки и прибыли | FR-03, BR-04, BR-05 |
| AC-04 | Стоимость списаний в SQL и Python совпадает | FR-05, BR-02 |
| AC-05 | XYZ не присваивает класс при < 6 пригодных неделях и исключает недели без товара | FR-04, BR-06 |
| AC-06 | Каждая рекомендация содержит 6 обязательных полей; нет рекомендаций «вывести из ассортимента» | FR-06, BR-09 |
| AC-07 | Выручка на экране «Обзор бизнеса» равна сумме SQL-задачи 1 | NFR-03 |
| AC-08 | Все экраны открываются без ошибок с фильтром точек и без него | FR-08, FR-10 |
